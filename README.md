# Low-Cost and Open-Sourced: DIY Remote Sensing Meteorological Monitoring Station


This project focuses on designing and building a low-cost, open-source meteorological station for environmental monitoring. It is designed for field deployment, featuring low power consumption and real-time wireless data transmission.

The station provides a budget-friendly, versatile alternative to commercial monitoring systems.
## 📊 Key Features & Measured Parameters
* **Air Temperature & Relative Humidity**
* **Barometric Pressure**
* **Precipitation (Rainfall)**
* **Wireless Real-Time Data Transmission** 
* **Solar / Battery Powered** for long-term field installation.
